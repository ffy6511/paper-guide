制大模型行为，微调太贵还可能“灾难性遗忘”，写 prompt 又只是表面功夫、没保证。</li>
<li>Steering 是折中办法：依据“线性表示假设”（概念在表示空间里是线性方向），直接改隐藏状态，不动权重。</li>
<li>但现有工具（repeng、pyreft、EasyEdit2）有三个毛病：<b>慢</b>（EasyEdit2 不支持批量推理）；<b>功能少</b>（缺少按 token 触发、多向量协同）；<b>难扩展</b>（不好接自己的新算法）。</li>
</ul>

<h3>方法要点（说人话版）</h3>
<p>核心公式就一行：<code>h' = h + α·v</code>——隐藏状态 h 加上概念向量 v，α 控制力度，正数增强、负数抑制。框架分四块：</p>
<ol>
<li><b>造向量</b>：分析类方法（CAA 正负样本均值差、PCA、线性探针、通过 Neuronpedia API 取 SAE 特征）和学习类方法（重构了 pyreft，支持 LoReFT、LM-Steer、监督加性向量 SAV 等）。</li>
<li><b>用向量</b>（核心，构建在 vLLM 上）：
 <ul>
 <li>非侵入式包装：维护一个“decoder 层类名”注册表，加载模型时自动套壳，不用为 LLaMA、Qwen 等逐个改代码；也支持视觉-语言模型。</li>
 <li>算法接口：<code>BaseSteerVectorAlgorithm</code> + 装饰器注册 + 懒加载工厂；还能改 MoE 的路由 logits。</li>
 <li>细粒度控制：<code>VectorConfig</code> / <code>SteerVectorRequest</code> 统一接口；可以按 token、位置、推理阶段触发；多个向量同时用，冲突时按用户指定策略（叠加、优先级等）处理。</li>
 </ul></li>
<li><b>资源库</b>：预计算好的向量和示例，覆盖 8 个场景：安全、推理、知识、真实性、语言、情感、人格、文风。</li>
<li><b>网页 Demo</b>：推理 / 对话 / 抽取 / 训练四个模块，可并排对比原始与 steer 后输出，支持中英文界面。</li>
</ol>
