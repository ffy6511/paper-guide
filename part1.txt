<h2><span class="no">①</span>EasySteer: A Unified Framework for High-Performance and Extensible LLM Steering</h2>
<div class="meta">作者：Haolei Xu, Xinyu Mei, Yuchen Yan, Rui Zhou, Wenqi Zhang, Weiming Lu*, Yueting Zhuang, Yongliang Shen*（*通讯作者）· 浙江大学<br>
arXiv 2509.25175（cs.CL）· v1 2025-09-29，当前 v3 2026-09-03 · arXiv 备注：<b>EMNLP 2026 System Demonstrations</b> · Apache-2.0 开源</div>
<div class="links">
<a class="btn" href="https://arxiv.org/abs/2509.25175" target="_blank" rel="noopener">arXiv 摘要页</a>
<a class="btn" href="https://arxiv.org/pdf/2509.25175" target="_blank" rel="noopener">PDF（群里分享的链接）</a>
<a class="btn" href="https://github.com/ZJU-REAL/EasySteer" target="_blank" rel="noopener">GitHub 代码</a>
<a class="btn" href="https://www.youtube.com/watch?v=3rRGzZmhrXg" target="_blank" rel="noopener">演示视频</a>
</div>
<div class="tldr"><b>一句话：</b>不重新训练模型，推理时往某几层的隐藏状态上“加一个方向向量”就能让模型少啰嗦、少胡说、换语气——EasySteer 把这件事塞进 vLLM，做得又快又好扩展。</div>

<h3>问题与动机</h3>
<ul>
<li>想控制大模型行为，微调太贵还可能“灾难性遗忘”，写 prompt 又只是表面功夫、没保证。</li>
<li>Steering 是折中办法：依据“线性表示假设”（概念在表示空间里是线性方向），直接改隐藏状态，不动权重。</li>
<li>但现有工具（repeng、pyreft、EasyEdit2）有三个毛病：<b>慢</b>（EasyEdit2 不支持批量推理）；<b>功能少</b>（缺少按 token 触发、多向量协同）；<b>难扩展</b>（不好接自己的新算法）。</li>
</ul>

<h3>方法要点（说人话版）</h3>
<p>核心公式就一行：<code>h' = h + α·v</code>——隐藏状态 h 加上概念向量 v，α 控制力度，正数增强、负数抑制。框架分四块：</p>
<ol>
<li><b>造向量</b>：分析类方法（CAA 正负样本均值差、PCA、线性探针、通过 Neuronpedia API 取 SAE 特征）和学习类方法（重构了 pyreft，支持 LoReFT、LM-Steer、监督加性向量 SAV 等）。</li>
<li><b>用向量</b>（核心，构建在 vLLM 上）：
 <ul>
 <li>非侵入式包装：维护一个“decoder 层类名”注册表，加载模型时自动套壳，不用为 LLaMA、Qwen 等逐个改代码；也支持视觉-语言模型。</li>
 <li>算法接口：<code>BaseSteerVectorAlgorithm</code> + 装饰器注册 + 懒加载工厂；还能改 MoE 的路由 logits。</li>
 <li>细粒度控制：<code>VectorConfig</code> / <code>
